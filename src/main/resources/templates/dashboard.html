Agent trajectories

Worked example: CASE.15.DUTY.VIOLATION

The three specialised agents disagree, and the disagreement changes nothing. The Boundary Agent proposes HUMAN_REQUIRED because preparation and approval resolve to the same role. The Repair Advisor proposes the smallest safe repair — return the approval step to a role other than the preparing role, rather than moving preparation. The Rule Mapper is weaker and wrong: it proposes only AUTO_WITH_EXCEPTION, at confidence 52.

The verifier neither votes nor averages. It blocks the unsafe variant on its own structural evidence — SEPARATION_OF_DUTIES_VIOLATED over the step pair S.PREPARE → S.APPROVE in the Findings section — and names LEGAL_REVIEWER as the required authority. The weaker Rule Mapper proposal cannot soften that outcome, and the per-case table under Baseline versus advanced shows the baseline architecture missing this case entirely.

Advisory only.

Every observation below is an agent proposal. The deterministic verifier independently determines the findings in the Findings section, the required reviewer role and the release outcome. No proposed tier, category, rationale or confidence value below can authorise, block or alter a release. AgentIndependenceTest reproduces every result on this page with each agent unavailable and with each agent returning hostile output.

Agents propose; they never decide. A trace with status SKIPPED means no fixture existed, and the verdicts are unaffected either way.
